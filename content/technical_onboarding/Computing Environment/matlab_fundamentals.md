## MATLAB Fundamentals

MATLAB is the primary programming language used in the lab for neuroimaging analysis, especially with SPM and GIFT. You need a working understanding of MATLAB before you can use GIFT, so complete this section before moving on to Analysis Methods.

## Why MATLAB?

SPM (the preprocessing tool) and GIFT (the ICA toolbox) are both MATLAB-based. You don't need to be a MATLAB expert, but you need to be comfortable enough to run scripts, modify parameters, and interpret errors.
