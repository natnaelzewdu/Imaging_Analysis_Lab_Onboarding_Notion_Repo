## Git & GitHub Basics

Learn version control with Git and how the lab uses GitHub for collaboration and code sharing. Git is essential for tracking your scripts, collaborating with lab members, and keeping your work reproducible.

### Tutorial — Start here

- 📺 [Git and GitHub for Beginners — full crash course (freeCodeCamp, 1 hr)](https://www.youtube.com/watch?v=RGOj5yH7evk)

### Recommended Resources

- [GitHub Skills — free interactive courses](https://skills.github.com/)

- [TReNDsCenter GitHub organization](https://github.com/trendscenter)

- [Pro Git book (free online)](https://git-scm.com/book/en/v2)

### Lab conventions

- All analysis scripts should be under version control

- Use the [TReNDsCenter GitHub](https://github.com/trendscenter) for lab-related repositories

- Commit early and often; write meaningful commit messages
